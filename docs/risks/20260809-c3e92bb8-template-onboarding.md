# RISK-c3e92bb8: starter テンプレが展開直後に評価を通らず最初の体験で行き止まる

## リスク

テンプレートは nput をはじめて使う人が最初に触れる成果物であり、展開した直後に評価が通らな
ければ、利用者は自分の書き方が悪いのか雛形が壊れているのか判断できないまま行き止まる。
テンプレートはプロダクト本体のコードから独立して壊れうる（本体の API を変えたときに追従を
忘れる）ため、本体のテストでは守れない。

固有の難しさは参照の循環にある。テンプレートは公開された nput を参照するので、リポジトリ内で
検証しようとすると「まだ公開されていない変更を含む手元の nput」ではなく公開版を見に行く。
これを局所の参照先へ差し替えられなければ、検証は手元の変更を反映しない。

加えて、nput が独自の flake 出力を持つことに由来する警告を、失敗と取り違える余地がある。
警告は許容する方針を採っているため、警告の有無ではなく評価が成功することで判定しなければ
ならない。

## 影響

新規利用者が最初の段階で離脱する。level を medium とするのは、既存の利用者の配置物を壊す
性質ではなく、影響が導入の局面に限られるため。
