# CASE-932e218b: niface_test.go — エンベロープ基礎形・id 導出・エラー分類・stdout 所有権

## 対象

`cmd/nput/niface_test.go`

## 検証内容

- **エンベロープ基礎形の適合** — subject の有無 × 成功 / 失敗、主体確立前の失敗と主体起因の
  失敗を表で網羅し、ツール名とバージョン・コマンド名・dryrun フラグが載ること。stdout に
  JSON 1 文書と改行だけが出ること
- **item id の他実装互換** — niface が配布する id ベクタを全件再現すること、entry 用の
  identity の形が同じ id を導くこと
- **エラー分類** — ビルド失敗のマーカーが再ラップを越えて生き残ること、ファイルシステム由来の
  sentinel が汎用の形状判定に優先すること、排他制御由来の分類、いずれにも当たらない失敗の
  汎用分類
- **`--json` 下の stdout 所有権** — 行指向の出力（計画・世代一覧・パス列挙）が全て止まり、
  既定の契約では出ること。stderr の人間向け通知は両契約で維持されること
- **run の開始と公開の網羅** — 各コマンドが run を開始して公開すること、登録済みの実行系
  サブコマンドが漏れなくその配線を持つこと、help / completion は run を開始せず文書も出さない
  こと
- **確認の合成** — 機械可読出力の指定が端末でもプロンプトを禁じ、同意フラグの無い実行が
  即座に止まること
- **出力の書き込み失敗** — 書き込みに失敗する出力先で失敗が伝播すること

固定クロックとバッファを用い、時刻とホスト環境に依存しない。他の CASE が使う run の
コンストラクタとデコーダをこのファイルが定義する。
