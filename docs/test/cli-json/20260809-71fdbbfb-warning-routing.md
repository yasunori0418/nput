# TC-71fdbbfb: warning が対象の有無で item と subject へ振り分けられ全種別がコードへ写る

## 条件

warning の置き場所が、その warning の指す対象がインベントリに存在するかどうかで決まることを
確かめる。インベントリに載っている対象への警告はその item が持ち、インベントリの外にある対象
（前世代にしか無い孤児・保守的判断で残した stale）への警告は subject が持つ。後者は item が
無い以上どの item にも紐づけられないため、警告自体が対象を自己完結して示す必要がある。

あわせて、engine 側の警告種別が漏れなく機械可読なコードへ写ることを確かめる。種別ごとの
対応を網羅的に見るのは、種別が増えたときに写像を足し忘れると、その警告だけが未知として
落ちるため。未知の種別が来たときのフォールバックも定める。

warning と error が同じ文書に同居する場合でも、文書が適合を保つことを確かめる。警告があること
と失敗していることは独立であり、警告の存在が失敗の表現を壊してはならない。
