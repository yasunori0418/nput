# TC-810d661d: 空親剪定の境界

target 除去後の親ディレクトリ剪定が、空である限り多階層を遡ること、および停止すべき境界で
止まることを検証する。境界は 3 つある: root 自体（root は消さない）、symlink である祖先
（その先へ踏み込まない）、非空のディレクトリ（foreign な実ファイルを含む場合を含む）。

剪定の失敗が警告に留まり apply 全体を落とさないこと、および剪定が走る経路（stale 除去後・
reset 後）と走らない経路（配置前除去。直後に同じ場所へ配置し直すため）が区別されていることを
条件に含む。同じディレクトリが二重に剪定報告されないことも含む。
