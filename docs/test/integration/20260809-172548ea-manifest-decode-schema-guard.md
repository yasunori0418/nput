# TC-172548ea: manifest の読み取りが v1 を正確に復元し未知の版とフィールドを検出可能に拒否する

## 条件

契約の消費側が、渡された文書をどう読みどう拒むかを確かめる。

- **v1 の正確な復元** — 配置元の種別・配置元・部分パス・配置先・配置方式・root の種別が
  定義どおりに読み取れること
- **未知の版の拒否** — 消費側が知らない版を受理せず、しかも**その理由が判別できる形で**
  拒否すること。呼び出し側が「pin した flake と CLI の版がずれている」という案内を出せる
  ことが契約であり、単にエラーになるだけでは足りない
- **未知のフィールドの拒否** — 知らないキーを黙って無視せず拒否すること。無視すると契約が
  暗黙に拡張され、届かなかった情報に誰も気づかない
- **root の種別ごとの扱い** — 評価時に絶対パスが決まる種別がパスを持つこと。対になる「実行時に
  解決する種別がパスを持たないこと」は現状アサートされておらず、この条件には含めない
- **文書が存在しない場合の失敗** — 配置物に文書が無ければ失敗すること

外部プロセスを起動せず、一時ディレクトリへ文書を直接書き出した fixture に対して評価する。
